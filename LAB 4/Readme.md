LEB 1: KNN on a Dataset of Your Choice 
เป็นการสร้างโมเดล Machine Learning แบบ Classification ด้วย K-Nearest Neighbors (KNN) โดยใช้ข้อมูลแมวเพื่อทำนายสายพันธุ์แมว (Breed) จากข้อมูลต่าง ๆ ได้แก่ อายุ เพศ ขนาด และลักษณะขน

ขั้นแรกทำการนำเข้า Dataset และตรวจสอบข้อมูล จากนั้นเลือกข้อมูลที่ต้องการใช้และจัดการค่าที่หายไป หลังจากนั้นแปลงข้อมูลประเภทข้อความให้เป็นตัวเลข เพื่อให้สามารถนำไปใช้กับโมเดล KNN ได้ แล้วแบ่งข้อมูลออกเป็น Training Set 80% และ Testing Set 20% พร้อมทำ Standardization เพื่อปรับข้อมูลให้อยู่ในช่วงที่เหมาะสม

จากนั้นสร้างโมเดล KNN และทดลองค่า k หลายค่า ได้แก่ 1, 3, 5, 7, 9 และ 11 เพื่อเปรียบเทียบประสิทธิภาพของแต่ละโมเดล โดยใช้ค่า Accuracy เป็นตัววัด นอกจากนี้ยังมีการทดลอง One-Hot Encoding และ 5-Fold Cross-Validation เพื่อประเมินความเหมาะสมของโมเดลเพิ่มเติม สุดท้ายใช้ Accuracy และ Classification Report ในการประเมินผลการทำนายของโมเดล
