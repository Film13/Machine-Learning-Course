แหล่งที่มาของ Dataset : https://www.kaggle.com/code/root31415/breed-classification/notebook
คำอธิบาย

1. lab1
เป็น Lab สำหรับ การทำนายข้อมูลแบบ Regression
ใช้ Simple Linear Regression เพื่อทำนายค่าจากตัวแปรอิสระเพียง 1 ตัว
ใช้ Multiple Linear Regression เพื่อทำนายค่าจากตัวแปรอิสระหลายตัว
เปรียบเทียบผลลัพธ์ของทั้งสองโมเดลว่าการใช้หลายตัวแปรช่วยเพิ่มความแม่นยำหรือไม่
ประเมินประสิทธิภาพของโมเดลด้วย R² Score, Mean Squared Error (MSE) และ Root Mean Squared Error (RMSE)
2. lab2
เป็น Lab สำหรับ การจำแนกข้อมูลแบบ Classification
เตรียมข้อมูลสำหรับงาน Classification โดยแปลงข้อมูลให้อยู่ในรูปแบบของคลาส
ใช้ Logistic Regression ในการสร้างโมเดลจำแนกข้อมูล
ทดลองทำนายผลและเปรียบเทียบค่าที่ทำนายกับค่าจริง
ประเมินผลด้วย Confusion Matrix, Accuracy และ Classification Report (Precision, Recall, F1-score)
3. lab3
เป็น Lab สำหรับ การเปรียบเทียบโมเดล (Model Comparison)
เปรียบเทียบ Simple Linear Regression และ Multiple Linear Regression
เปรียบเทียบผลการทำงานของ Training Set และ Testing Set
เปรียบเทียบการแก้ปัญหาแบบ Regression และ Classification
วิเคราะห์ประสิทธิภาพของโมเดลด้วย R² Score, MSE, RMSE, Accuracy และ Confusion Matrix
สรุปข้อดี ข้อจำกัด และเลือกโมเดลที่เหมาะสมกับลักษณะของข้อมูล
