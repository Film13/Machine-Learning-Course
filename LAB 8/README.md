# LAB: DCNN กับชุดข้อมูลที่เลือก

## 1. เกี่ยวกับโปรเจกต์
โปรเจกต์นี้เป็นการทดลองใช้ Deep Convolutional Neural Network (DCNN) เพื่อจำแนกสายพันธุ์แมวจากข้อมูลในไฟล์ `cats(1)(3).csv` โดยใช้ข้อมูลคุณลักษณะ เช่น อายุ เพศ ขนาด และความยาวขน เพื่อทำนายสายพันธุ์แมว

**หมายเหตุ:** ไฟล์ CSV นี้มีข้อมูลรายละเอียดและ URL ของรูปภาพ แต่ไม่มีข้อมูลพิกเซลของภาพโดยตรง ดังนั้น Notebook นี้จึงใช้ 1D-CNN กับข้อมูลตาราง ไม่ใช่การจำแนกจากภาพแมวจริง

## 2. Notebook ทำอะไรบ้าง
1. โหลดและตรวจสอบข้อมูลจากไฟล์ CSV
2. แบ่งข้อมูลออกเป็นชุดฝึกสอน (Training Set) และชุดทดสอบ (Testing Set)
3. แปลงข้อมูลประเภทข้อความเป็นตัวเลข และปรับมาตรฐานข้อมูลก่อนฝึกโมเดล
4. สร้างโมเดล DCNN จำนวน 2 รูปแบบ โดยมีจำนวนชั้น Convolution แตกต่างกัน
5. ฝึกโมเดลด้วยจำนวน Epoch สูงสุด 10, 20 และ 30 รอบ
6. ประเมินและเปรียบเทียบผลด้วย Accuracy และ Loss
7. แสดงกราฟ Training Accuracy, Validation Accuracy, Training Loss และ Validation Loss
8. แสดง Confusion Matrix, Classification Report และตัวอย่างผลการทำนาย

## 3. ไฟล์ที่ใช้
- `DCNN_Cats_Dataset.ipynb` — Notebook ที่มีโค้ด คำอธิบาย และกราฟผลการทดลอง
- `cats(1)(3).csv` — ชุดข้อมูลที่ใช้ฝึกและทดสอบโมเดล ควรวางไว้ในโฟลเดอร์เดียวกับ Notebook

## 4. ไลบรารีที่จำเป็น
โปรเจกต์นี้ใช้ Python และไลบรารีต่อไปนี้
- pandas
- numpy
- matplotlib
- scikit-learn
- TensorFlow

ติดตั้งไลบรารีด้วยคำสั่ง:

```bash
pip install pandas numpy matplotlib scikit-learn tensorflow
```

หากติดตั้ง TensorFlow ไม่สำเร็จ อาจเป็นเพราะเวอร์ชัน Python หรือระบบปฏิบัติการไม่รองรับ ให้ใช้ Python เวอร์ชันที่ TensorFlow รองรับ

## 5. วิธีใช้งาน
1. ดาวน์โหลด `DCNN_Cats_Dataset.ipynb` และ `cats(1)(3).csv`
2. วางไฟล์ทั้งสองไว้ในโฟลเดอร์เดียวกัน
3. เปิด Notebook ด้วย Jupyter Notebook หรือ VS Code
4. เลือก Python Environment ที่ติดตั้งไลบรารีครบแล้ว
5. รันเซลล์จากบนลงล่างตามลำดับ
6. ตรวจสอบตารางผลการทดลองและกราฟที่แสดงหลังรันเสร็จ

## 6. ผลลัพธ์ที่ได้
เมื่อรัน Notebook ครบทุกเซลล์ จะได้:
- ตารางเปรียบเทียบ Test Accuracy ของแต่ละโมเดลและจำนวน Epoch
- กราฟเปรียบเทียบ Accuracy ตามจำนวน Epoch
- กราฟ Training และ Validation Accuracy/Loss
- Confusion Matrix และ Classification Report
- ตารางเปรียบเทียบสายพันธุ์จริงกับสายพันธุ์ที่โมเดลทำนาย

ค่า Accuracy จริงจะปรากฏหลังจากรันโค้ด ไม่ควรกำหนดค่าผลลัพธ์ไว้ล่วงหน้า เพราะผลอาจแตกต่างกันตามสภาพแวดล้อมและการฝึกโมเดล

## 7. สรุป
โปรเจกต์นี้ทดลองเปรียบเทียบโมเดล 1D-CNN สองรูปแบบและจำนวน Epoch หลายค่า เพื่อศึกษาว่าโครงสร้างโมเดลและจำนวนรอบการฝึกมีผลต่อความแม่นยำอย่างไร ผลการทดลองสามารถนำมาใช้เปรียบเทียบประสิทธิภาพของโมเดลและดูแนวโน้มการเกิด Overfitting จากกราฟ Training และ Validation ได้

เนื่องจากชุดข้อมูลมีขนาดไม่มากและใช้ข้อมูลคุณลักษณะของแมวแทนภาพจริง ผลลัพธ์จึงเหมาะสำหรับการศึกษาและทดลองในห้องเรียน ไม่ควรสรุปว่าเป็นระบบ AI สำหรับจำแนกสายพันธุ์จากรูปภาพโดยตรง
